# Code and data availability

The code and supporting data for *Exact ctFMNL Assortment Optimization* are available at:

https://github.com/AMTOPA/ctFMNL

Release: https://github.com/AMTOPA/ctFMNL/releases/tag/v0.1.0

The repository contains the FABS and SPAR implementations, comparison and ablation solvers, automated tests, synthetic-input generation code for the experimental scales, batch experiment scripts, 100 small-instance exactness inputs, scale examples, and the Section 6.2 plotting data and figures. Generation commands, random seeds, instance counts and data formats are documented in `data/README.md`.
